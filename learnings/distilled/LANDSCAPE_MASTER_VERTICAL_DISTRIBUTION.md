# Landscape Master / Vertical Distribution

- status: distilled rule
- maturity_candidate: L1
- date: 2026-09-07
- source_project: M-FIELD

## 決策

以電影感、空間關係與環境尺度為主要敘事資產的超短篇連續劇，正式主版本採 `16:9` 橫屏；`9:16` 豎屏版本是獨立重剪與重構圖的發行版本，不是主片的自動中央裁切。

目前建議基線：

- 主片：`16:9`，每集約 `60-120 秒`。
- Previs／低成本測試：可使用 `720p`。
- 正式主片交付：至少 `1080p`。
- 社群導流版：`9:16`，通常 `20-45 秒`，依平台與段落重新選鏡、重構圖、重做字幕安全區。
- 拍攝與生成時，在不犧牲橫屏構圖的前提下，讓關鍵角色與必要動作保有可供豎屏重構的空間。

製片口訣：**橫屏建立電影宇宙，豎屏把觀眾帶進來。**

## 為什麼

橫屏較能保存角色、地標、環境反應與運動方向之間的水平空間關係，特別適合巨型角色、場面調度、災難場景與多鏡位連續動作。直接把橫屏主片中央裁成豎屏，容易切掉尺度參照、反應角色、移動方向、橋樑或地景，進而破壞敘事與連戲。

豎屏則更適合行動裝置上的角色近景、單一動作焦點、笑點與懸念鉤子。因此它應被視為同一素材的第二次導演與剪輯，而不是單純的輸出尺寸。

## 適用情況

- 電影感或偽紀錄片式的短篇連續劇。
- 環境、尺度、群體反應或水平運動是敘事資訊的場景。
- 同一事件需要多鏡位連續性與精確空間關係。
- 主片與社群導流片有不同觀看任務。

## 不適用情況

- 作品從劇本、表演、場面調度到發行都明確採平台原生豎屏。
- 單人直視鏡頭、肖像式表演或介面操作本來就是主要畫面語法。
- 委託方或播出平台明定唯一交付格式，且沒有橫屏主版本需求。

## Preflight Gate

發行格式定案前必須確認：

1. 主片與社群版的敘事任務是否分開定義。
2. `16:9` 與 `9:16` 是否使用獨立 timeline／shot decision，而非批次中央裁切。
3. 每個豎屏鏡頭是否仍保留主體、動作方向、尺度參照與必要反應資訊。
4. 豎屏版字幕、人物視線與重要畫面元素是否通過目標平台的安全區檢查。
5. 若原鏡頭無法可靠重構，是否改用替代 take、插入鏡頭或重新生成，而非勉強裁切。

## 可固化項目

- Manifest 欄位：`master_aspect_ratio`、`distribution_aspect_ratio`、`episode_duration`、`cutdown_duration`、`delivery_resolution`。
- 自動檢查：禁止將只有 crop transform、沒有人工 shot review 的 `16:9 → 9:16` timeline 標記為 final。
- 構圖檢查：輸出平台別 safe-area overlay，逐鏡確認主體、字幕與尺度參照。

## 升級條件

在正式集數的橫屏主片與豎屏導流版中反覆驗證，並保存觀眾理解、連戲完整度、構圖失敗與返工成本的 evidence；通過可重複 checklist 後，才可升級為 Validated Skill 或 Studio Standard。
