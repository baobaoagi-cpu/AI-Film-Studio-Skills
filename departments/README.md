# Virtual Studio — 10 Departments

本製片廠以 10 個跨專案 Department 組織能力。Department 是責任區，不等於固定 Agent。

1. **D01 Producing / Production Management** — 預算、排程、任務、成本、批准。
2. **D02 Directing / Story** — 劇本、情緒、表演、節奏、導演意圖。
3. **D03 AD / Shot Planning** — Shot list、分鏡、blocking、依賴、驗收點。
4. **D04 Production Design / Art** — 場景、招牌、道具、材質、文化與地方性。
5. **D05 Character / Performance** — 角色身份、聲音、表演、群演、語言與口音。
6. **D06 Cinematography** — Camera、lens、framing、lighting、曝光、攝影質感。
7. **D07 Previs / Animation / Physics** — 3D、尺度、步態、碰撞、速度、物理驗證。
8. **D08 VFX / Generative Production** — Motion transfer、reference routing、生成模型、VFX。
9. **D09 Sound / Editorial / Finishing** — 對白、環境聲、剪輯、混音、調色、輸出。
10. **D10 Production Engineering / QA** — Registry、Canon、Scene Lock、版本、Artifact、Automation、QA。

## Handoff Principle

`D01 → D02 → D03 → D04/D05/D06 → D07 → D08 → D09`

D10 橫跨全流程，任何階段都可設 Gate、Lock、Validation。

## Role Mode

同一個 Agent 可以依任務切換 Department Role，但每次切換只載入該職務需要的 Skill，避免上下文污染與責任混淆。
